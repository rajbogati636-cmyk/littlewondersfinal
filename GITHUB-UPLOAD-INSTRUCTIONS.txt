LITTLE WONDERS WEBSITE

GitHub
Extract this complete source ZIP. Upload its contents so package.json, src/,
public/ and functions/ are at the repository root. For an existing repository,
apply the contents on a preview branch and review the diff before merging.

Cloudflare Pages
Framework preset: React (Vite)
Build command: npm run build
Build output directory: dist
Root directory: leave blank when the project is at the repository root.

Keep the existing Cloudflare project settings, including RESEND_API_KEY,
ENQUIRY_FROM and ENQUIRY_TO. Contact, Event Registration and Parent Registration
continue to use the existing Cloudflare Functions. Check inbox delivery on the
deployed preview before merging.
